# LinkedIn Poster (링크드인 글 자동 게시기)

뮤즈에게 링크드인 자동 투고를 시키기 위해, 링크드인 **공식 API**로 내 계정에 글을 올리는 타입스크립트 프로그램입니다.

```bash
npm run post -- "올리고 싶은 글 내용"
```

---

## 0. 전체 흐름 한눈에 보기

| 단계 | 할 일 | 횟수 |
|---|---|---|
| 1 | 링크드인 개발자 앱 만들기 (웹사이트에서 클릭) | 처음 1번 |
| 2 | 내 컴퓨터 준비 (Node.js 설치, 패키지 설치, `.env` 작성) | 처음 1번 |
| 3 | 로그인: `npm run login` | 처음 1번 + 60일마다 |
| 4 | 글 올리기: `npm run post -- "..."` | 올릴 때마다 |

---

## 1. 사전 준비물

- **링크드인 계정**: 글을 올릴 본인 계정
- **Node.js 24.22.1 이상 (24.x 계열)**
  - 2026년 10월 21일 보안 릴리스(취약점을 고친 정식 배포판)에서 24.x 계열의 패치(수정) 버전이 **24.22.1**입니다. 이 버전 **이상**을 쓰세요.
  - 설치 확인: 터미널(명령어 입력창)에서 `node -v` 입력 → `v24.22.1` 이상이면 OK
  - 그보다 낮으면(예: `v24.14.1`, `v20.x`) 보안 취약점이 남아 있으니 업데이트하세요.
  - 없거나 낮으면 https://nodejs.org 에서 **24.x 최신판(LTS, 오래 지원해 주는 안정 버전)** 을 설치
- **링크드인 회사 페이지 1개**: 앱을 만들 때 "이 앱이 어느 회사 소속인가"를 물어봐서 필요합니다.
  - 회사가 없어도 괜찮아요. 개인용 빈 페이지를 새로 만들어 연결하면 됩니다.

## 2. 링크드인 개발자 앱 만들기 (가장 중요한 사전 작업)

링크드인은 "누가 API를 쓰는지" 알아야 하기 때문에, 먼저 **앱**(내 프로그램의 신분증)을 등록해야 합니다.

### 2-1. 앱 생성
1. https://developer.linkedin.com/ 접속 후 로그인
2. **My apps → Create app** 클릭
3. 입력 항목
   - **App name**: 아무 이름 (예: `my-linkedin-poster`)
   - **LinkedIn Page**: 위에서 준비한 회사 페이지 선택
   - **App logo**: 아무 이미지 (필수 항목)
4. 약관에 동의하고 **Create app**

### 2-2. 필요한 기능(Products) 추가
앱 화면의 **Products** 탭에서 아래 두 개를 **Request access**(사용 신청)로 추가합니다. 둘 다 별도 심사 없이 바로 켜집니다.

| 추가할 Product | 하는 일 | 얻는 권한(scope) |
|---|---|---|
| **Share on LinkedIn** | 내 계정 이름으로 글 쓰기 | `w_member_social` |
| **Sign In with LinkedIn using OpenID Connect** | "내가 누구인지" 확인 (로그인 인증 방식의 하나) | `openid`, `profile` |


### 2-3. 되돌아올 주소(Redirect URL) 등록
1. **Auth** 탭 → **OAuth 2.0 settings** → **Redirect URLs** 옆 연필 아이콘 클릭
2. 아래 주소를 추가하고 저장

```
http://localhost:3000/callback
```

> Redirect URL(되돌아올 주소)이란, 로그인을 마친 뒤 링크드인이 사용자를 돌려보내는 주소입니다. `localhost`는 "내 컴퓨터 자신"을 뜻해요.
> `.env`의 `REDIRECT_URI`와 여기 등록한 주소가 다르면 로그인이 실패합니다.

### 2-4. 열쇠 2개 복사해 두기
**Auth** 탭 상단에서 아래 두 값을 확인합니다.

- **Client ID**: 앱의 아이디
- **Client Secret**: 앱의 비밀번호 (**절대 남에게 보여주거나 깃허브에 올리지 마세요**)

## 3. 내 컴퓨터 설정

```bash
# 1) 프로젝트 폴더로 이동
cd linkedin-poster

# 2) Node 버전 확인
node -v

# 3) 필요한 부품(패키지) 설치
npm install

# 4) 설정 파일 만들기
cp .env.example .env        # Windows(명령 프롬프트)는: copy .env.example .env
```

`.env` 파일을 열어 값을 채웁니다.

```env
LINKEDIN_CLIENT_ID=2-4에서 복사한 Client ID
LINKEDIN_CLIENT_SECRET=2-4에서 복사한 Client Secret
REDIRECT_URI=http://localhost:3000/callback
LINKEDIN_VERSION=202608
```

- `LINKEDIN_VERSION`은 링크드인 API의 버전(`연도+월` 6자리)입니다. 오래된 버전은 링크드인이 주기적으로 막기 때문에, 버전 관련 오류가 나면 더 최근 달(예: `202610`)로 바꿔 보세요.

## 4. 로그인

```bash
npm run login
```

1. 터미널에 긴 주소가 나옵니다. 그걸 복사해서 브라우저에 붙여넣으세요.
2. 링크드인 로그인 후 **허용(Allow)** 을 누릅니다.
3. "로그인 완료!" 화면이 뜨면 성공이고, 터미널로 돌아가면 됩니다.
4. 프로젝트 폴더에 `.token.json` 파일이 생깁니다. 이 파일이 **출입증(액세스 토큰)** 입니다.

> 출입증은 약 **60일** 동안 유효합니다. 만료되면 `npm run login`을 다시 실행하세요.

## 5. 글 올리기

```bash
npm run post -- "안녕하세요! API로 올리는 첫 글입니다."
```

성공하면 새 글의 주소가 출력됩니다. 링크드인 피드에서도 확인해 보세요.

이미지를 붙이려면 `--image`를, 외부 글 링크 카드를 붙이려면 `--url`을 추가하세요.

```bash
# 이미지 첨부
npm run post -- "사진과 함께 올리는 글" --image 사진.png

# 링크 카드 첨부 (본문은 외부 주소에 있고, 글에는 링크 카드가 붙습니다)
npm run post -- "글을 공유합니다" --url https://example.com

# 링크 카드에 썸네일 이미지도 함께
npm run post -- "글을 공유합니다" --url https://example.com --image 썸네일.png
```

## 6. 뮤즈(Muse)와 연결하는 방식 — 왜 반자동인가

뮤즈에게 게시를 시키는 연결은 지금 **반자동**으로 설정돼 있습니다. 구조는 두 단계입니다.

1. **출입증 발급은 내 컴퓨터에서**: 이 프로그램으로 `npm run login`을 실행해 출입증(액세스 토큰)을 받습니다.
2. **발급된 출입증을 뮤즈의 보안 금고(Secure Vault)에 등록**: 그 뒤로는 뮤즈가 금고의 출입증으로 링크드인 공식 API를 직접 호출합니다. 출입증 원문은 워크스페이스의 파일이나 코드에 들어 있지 않습니다.

완전 자동(뮤즈가 알아서 OAuth로 연결)이 안 되는 이유는 확인까지 마쳤습니다.

- 뮤즈의 호스팅 OAuth 연결로 링크드인과 토큰 교환을 시도하면 `401 invalid_client` 오류가 반복됩니다. 인증 방식을 링크드인이 요구하는 `client_secret_post`로 맞추고, 불필요한 파라미터를 빼고 재시도해도 결과는 같았습니다. (2026-11-03 재시도 포함)
- 반면 **같은 앱, 같은 Client ID/Secret**으로 이 프로그램이 직접 토큰 교환을 하면 성공합니다. 즉 앱이나 자격증명의 문제가 아니라, 뮤즈 측 호스팅 연결 흐름과 링크드인의 토큰 교환 방식이 맞지 않는 것입니다.
- 그래서 교환이 끝난 결과물인 출입증만 금고로 넘기는 방식으로 우회했습니다. 막힌 구간(토큰 교환)을 건너뛰면 나머지 API 호출은 정상 동작합니다.

이 반자동 구조에서 사람이 할 일은 하나뿐입니다.

- 출입증은 약 60일마다 만료되고 자동 갱신(리프레시)이 없어서, 만료 때마다 내 컴퓨터에서 `npm run login`으로 새로 발급받아 금고에 다시 등록해야 합니다. 현재 등록된 출입증의 유효기간은 **2026-12-31**까지입니다.

검증 상태 (2026-11-03):

- 뮤즈 워크스페이스에서 금고의 출입증으로 프로필 조회(`GET /v2/userinfo`)를 호출해 **HTTP 200** 성공을 확인했습니다.
- 게시 호출도 이 연결로 구성돼 있으나, 실제 게시 성공 여부는 아직 검증 전입니다.

## 7. 보안 주의사항

- `.env` (Client Secret 포함)와 `.token.json` (출입증)은 **비밀번호와 같습니다.**
  - 깃허브, 메신저, 스크린샷 등으로 공유하지 마세요.
  - 이미 `.gitignore`(깃에 올리지 않을 파일 목록)에 들어 있습니다.
- 유출이 의심되면 개발자 사이트 **Auth** 탭에서 Client Secret을 다시 발급(재생성)하세요.
- 이 프로그램은 **내 개인 계정**용입니다. 링크드인 이용약관과 API 약관을 지켜서 사용하세요. (스팸성 대량 게시는 계정 제한 사유가 될 수 있어요.)

## 8. 할 수 없는 것 (이 프로젝트의 범위 밖)

- **LinkedIn 네이티브 아티클(긴 글) 쓰기**: LinkedIn 안에서 직접 쓰는 긴 글은 공식 API가 없어서 프로그램으로 올릴 수 없습니다. LinkedIn 웹사이트에서 직접 써야 합니다. (외부 글 주소를 연결하는 링크 공유 글은 가능합니다.)
- **이미지·링크를 글 중간에 넣기**: 첨부물(이미지, 링크 카드)은 항상 글 아래쪽 고정된 자리에만 붙고, 글 중간에 끼워 넣을 수 없습니다. 이는 이 프로그램의 한계가 아니라 LinkedIn 게시물 자체의 사양이라, LinkedIn 앱에서 직접 올려도 동일합니다.
